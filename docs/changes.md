Before making any changes, checkout to branch `master`. Then run the command `git pull`, then checkout to a new branch when you will be making a change to code. Always prefix your branch name with "sonny-" and name the branch something simple. I.E. if you will be changing the nav layout, your branch should be called: "sonny-nav-layout-change". Always use "-" in between words. Once the change is completed, use "git add .", then "git commit -m '`a short commit message describing the change goes here`'", then "git push". Once you have pushed the changes up, create a github merge request. You can use gh for this.
