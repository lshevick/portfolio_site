Redline

An LLM-powered code reviewer that runs in CI and comments on every pull request.

Redline is a bot that lives in your CI pipeline. It reads the diff of every pull request, runs an LLM over it, and posts back prioritized feedback — bugs, security smells, and style nits — as comments on the PR.

The interesting part wasn't calling the API; it was teaching the model to stop inventing line numbers. Getting it to cite real hunks reliably took most of the work.

What's involved

  • Diff parsingTurning a git patch into structured hunks the model can actually reason about.
  • Prompt & contextTuning system prompts and diff size so reviews stay focused and cheap.
  • Hallucination guardrailsForcing the model to cite line numbers it can back up, with a confidence score.
  • CI integrationPosting comments and verdicts back into GitHub pull requests via Actions.
